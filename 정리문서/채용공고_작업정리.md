# 마음잇기 — 채용공고 UI/UX 작업 정리

담당 파트: 채용공고(잡코리아/사람인 API 연계) 화면의 UI/UX 설계
작성 기준: API(잡코리아/사람인)는 신청만 해두고 아직 발급 전이라, 더미데이터로 화면·기능을 먼저 완성하고 나중에 API 응답으로 갈아끼우는 구조로 진행함.

## 1. 완성된 기능

### 채용공고 페이지 (`src/pages/app/Jobs.jsx`)
- 상단 히어로 배너 (잡코리아 스마트픽 참고, 브랜드 컬러인 ink→coral 그라데이션으로 재구성)
- 키워드 검색 + 지역 검색 카드
- 지역 필터: 광역시 7개 + 도 단위를 그룹 구분 없이 하나의 리스트로 표시 (처음엔 특별시/도 묶음으로 만들었다가, 그룹을 없애고 지역만 쭉 나열하는 방식으로 변경)
- 카테고리 필터 칩: 신입/인턴 + 5개 대분류(IT/SW, 디자인, 공공·복지, 식·음료, MD/상품기획)
- "스마트픽" TOP3 추천 섹션: 선호 추천 분야에 맞는 공고를 우선 노출
- 전체 채용공고 목록: 키워드/지역/카테고리 조건으로 필터링, D-day 표시(`formatDday`)
- API 발급 전이라는 안내 문구 섹션

### 더미데이터 (`src/mocks/jobs.js`, `src/constants/jobCategories.js`)
- 5개 대분류, 37개 세부직무 기준으로 더미 채용공고 총 370건 생성 (세부직무당 10건)
- 지역/기업명/태그/마감일을 카테고리별로 다르게 순환시켜서 실제 공고처럼 보이게 구성 (완전 랜덤이 아니라 재현 가능한 방식)
- Jobs.jsx에서 데이터를 완전히 분리해서, 배포 시점엔 Jobs.jsx가 로직만 남고 데이터는 API 응답으로 교체될 수 있게 정리

### 선호 추천 분야 실시간 공유 (`src/context/PreferenceContext.jsx`)
- "선호 추천 분야" = 적성 검사 결과 60% + 채팅 상담 분석 결과 40%를 합산해서 자동 결정
- React Context로 구현해서, 검사/채팅 어느 쪽에서든 결과가 나오는 시점에 `setTestResult(...)` / `setChatResult(...)`만 호출하면 채용공고 스마트픽·마이페이지 등 이 값을 구독하는 모든 화면이 동시에 실시간 갱신됨
- `resetPreference()`로 진단 결과 초기화 가능
- Provider 없이 렌더링되는 화면(로그인 전 랜딩의 Header)에서도 에러 없이 안전한 기본값을 반환하도록 처리

### 진단하기 테스트 (`src/components/PreferenceQuiz.jsx`)
- 실제 KcELECTRA/SBERT 적성 검사·채팅 분석이 붙기 전, "검사 60%" 부분을 손으로 확인해볼 수 있는 임시 5문항 진단
- 질문 5개 × 선택지 5개, 각 선택지가 5개 대분류에 1:1 대응
- 응답 결과를 비율 벡터(예: `{ 'IT/SW': 0.6, '디자인': 0.4 }`)로 계산해서 `setTestResult`에 전달

### 진단하기 UI 배치 (`src/components/Header.jsx`)
- 처음엔 마이페이지 안에 인라인 카드 → 오른쪽 슬라이드 패널 → 마이페이지 헤더의 박스+중앙 모달 순으로 시도했다가, 최종적으로 **최상단 전역 네비게이션 바**로 이동
- 로그인 상태일 때 "test22님" 이름 왼쪽에 coral 색 알약 모양 "진단하기" 박스 표시 (진단 전엔 "진단하기", 진단 후엔 결과 카테고리명 표시)
- 클릭하면 화면 정중앙에 5문항 진단 모달이 뜨고, 배경 클릭/Esc로 닫힘
- 홈/채팅/채용공고/마이페이지 등 로그인 후 어느 화면에서도 항상 노출됨 (헤더가 공통 컴포넌트라서)

### 마이페이지 (`src/pages/app/MyPage.jsx`)
- 기존 자유 입력 방식이던 "선호 추천 분야"를 없애고, `usePreference()`로 실시간 값을 읽어와 표시
- "내 정보" 카드에 선호 추천 분야 값 + "초기화" 버튼 배치
- 진단하기 박스/모달은 Header로 옮겨갔기 때문에, 마이페이지에는 값 표시 전용 코드만 남김

## 2. 파일 구조 정리

| 파일 | 역할 |
|---|---|
| `src/pages/app/Jobs.jsx` | 채용공고 페이지 전체 (검색/필터/스마트픽/목록) |
| `src/mocks/jobs.js` | 더미 채용공고 370건 |
| `src/constants/jobCategories.js` | 5개 대분류 + 37개 세부직무 목록 |
| `src/context/PreferenceContext.jsx` | 선호 추천 분야 상태 관리 (검사 60% + 채팅 40%) |
| `src/components/PreferenceQuiz.jsx` | 5문항 진단 테스트 UI |
| `src/components/Header.jsx` | 전역 상단 네비게이션 + 진단하기 박스/모달 |
| `src/pages/app/MyPage.jsx` | 마이페이지 (선호 추천 분야 표시 + 초기화) |
| `src/pages/app/AppLayout.jsx` | 로그인 후 레이아웃, `PreferenceProvider`로 전체를 감쌈 |

## 3. 앞으로 남은 작업

- 잡코리아/사람인 API 발급 완료 시, `src/mocks/jobs.js`의 더미데이터를 실제 API 응답으로 교체
- 실제 KcELECTRA/SBERT 적성 검사 결과가 나오는 화면에서 `usePreference().setTestResult(...)` 연동 (현재는 `PreferenceQuiz`가 임시로 이 역할을 대신함)
- 실제 GPT+RAG 채팅 상담 분석 결과가 나오는 화면에서 `usePreference().setChatResult(...)` 연동
- 채용공고 상세 페이지, 스크랩/지원 등 후속 기능 설계
